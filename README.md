# Google Cloud Engineering Lab

Repositorio de aprendizaje práctico de Google Cloud organizado como una progresión pedagógica:

1. **Cloud Digital Leader (CDL)** — fundamentos, negocio y capacidades cloud.
2. **Associate Cloud Engineer (ACE)** — configuración, despliegue, operación y seguridad.
3. **Professional Cloud Architect (PCA)** — diseño, trade-offs y excelencia arquitectónica.

La clasificación primaria de cada recurso es siempre:

`Certificación → Área del examen → Producto o capability → Lab → Evidence`

Los materiales compartidos y las referencias comunes viven en [`shared/`](shared/).

## Progresión

| Nivel | Pregunta guía | Enfoque |
|---|---|---|
| CDL | What / Why? | Fundamentos y transformación empresarial |
| ACE | How do I build and operate it? | Implementación y operación |
| PCA | How should the whole system be designed? | Arquitectura y decisiones |
