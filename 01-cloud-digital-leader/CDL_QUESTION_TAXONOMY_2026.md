# Taxonomía de preguntas CDL 2026

## Base utilizada

La guía oficial organiza el contenido por seis dominios y el examen estándar utiliza preguntas de opción múltiple y selección múltiple. La guía beta reciente añade IA generativa, IA agéntica, plataformas de agentes, selección de modelos y seguridad de IA. Las preguntas oficiales de muestra sirven para conocer formato y contenido de ejemplo, pero Google advierte que no representan todo el rango ni la dificultad del examen.

## Taxonomía cognitiva

| Código | Tipo | Qué exige |
|---|---|---|
| `recognize` | Reconocimiento | Identificar una definición, servicio o concepto |
| `compare` | Comparación | Distinguir modelos, productos o trade-offs |
| `apply` | Aplicación | Elegir una solución para un caso de negocio |
| `evaluate` | Evaluación | Juzgar riesgo, seguridad, confiabilidad o arquitectura |

## Patrones de pregunta

| Patrón | Uso |
|---|---|
| `definition` | Conceptos básicos del blueprint |
| `product-selection` | Relacionar necesidad con producto o API |
| `api-matching` | Seleccionar API según entrada o problema |
| `business-scenario` | Aplicar conocimiento a una organización |
| `tradeoff` | Comparar costo, control, velocidad, esfuerzo o riesgo |
| `migration-strategy` | Elegir rehost, replatform, refactor, retain o retire |
| `agent-workflow` | Herramientas, aprobación, memoria, evaluación y MCP |
| `responsible-ai` | Explicabilidad, privacidad, sesgo y supervisión |
| `security-control` | IAM, mínimo privilegio, perímetro y defensa en profundidad |
| `observability` | Métricas, logs, trazas, errores y señales operativas |
| `architecture-choice` | Decisiones completas de arquitectura |

## Distribución del banco

El banco contiene 96 preguntas, ocho por dominio:

- 48 preguntas base de fundamentos.
- 48 preguntas adicionales de aplicación, comparación, evaluación y casos empresariales.
- Preguntas explícitas de IA agéntica, selección de modelos, APIs, RAG, MCP, Model Armor, seguridad de tools, evaluación y operación de agentes.

## Tipos de respuesta

- `single_choice`: una respuesta correcta.
- `multi_select`: dos o más respuestas correctas.

En las sesiones de práctica se debe indicar siempre si la pregunta permite una o varias respuestas. Las opciones incorrectas deben ser plausibles, pero no ambiguas ni dependientes de información que no aparezca en el escenario.
